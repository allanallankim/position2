# 크롬 확장 프로그램 설치

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `extension` 폴더를 선택합니다.
4. 확장 프로그램 아이콘을 클릭해 분석 탭을 엽니다.
5. **시작하기 (웹캠 연동)**를 누르고 카메라 권한을 허용합니다.
6. 바른 자세로 **바른 자세 기준 설정 (3초)**를 진행합니다.
7. 다른 웹사이트로 이동합니다. 이미 열려 있던 웹페이지는 새로고침해야 위젯이 나타납니다.

오른쪽 아래 위젯은 100점 만점의 점수와 상태를 표시합니다.

- 초록: 85점 이상이며 자세 경고 없음
- 노랑: 70~84점이거나 하나의 자세 경고 발생
- 빨강: 70점 미만이거나 여러 자세 경고 발생
- 회색 / `—`: 정지, 인식 대기, 또는 15초 이상 새 결과 없음

위젯을 클릭하면 분석 탭으로 이동합니다. ×를 누르면 해당 페이지에서 숨겨지며 새로고침하면 다시 나타납니다.
분석 탭에서도 위젯을 확인할 수 있습니다. 카메라 정지 버튼은 실제 카메라 스트림도 해제합니다.

카메라는 확장 프로그램의 백그라운드 문서에서 실행됩니다. 웹페이지 이동, 새로고침, 탭 전환, 분석 화면 닫기에도 측정이 계속됩니다. 분석 화면을 다시 열면 실행 중인 카메라에 연결하며 카메라를 중복 실행하지 않습니다.
카메라를 끄려면 위젯을 클릭해 분석 화면에서 **일시 정지**를 누르세요. 브라우저 종료, 확장 프로그램 새로고침/비활성화 시에도 카메라가 해제됩니다. 브라우저를 다시 실행한 뒤에는 직접 분석을 시작해야 합니다.
절전/최대 절전 중에는 분석이 멈출 수 있습니다. 카메라 연결이 끊기면 상태를 표시하며 사용자가 다시 시작해야 합니다.
`chrome://` 설정 화면, Chrome 웹 스토어 등 Chrome이 확장 실행을 막는 페이지에는 위젯이 표시되지 않습니다.

모델과 실행 코드는 확장 폴더에 포함됩니다. 카메라 영상은 해당 PC에서 처리하며, 일반 웹페이지에는 점수와 상태만 전달합니다. 미리보기 영상은 분석 화면에서만 요청합니다.
기준 자세는 확장 프로그램의 로컬 저장소에 보관됩니다. 기존 웹앱의 쿠키와는 별개입니다.
이 버전은 개발자 모드 설치용이며 웹 스토어에 게시하지 않았습니다.

## 다시 빌드하기

저장소 루트에서 `npm ci` 후 `npm run build`를 실행합니다. 원본 `index.html`의 분석 로직과 UI를 바탕으로 `monitor.html`, `app.js`, `app.css`, 모델 파일을 생성합니다.
생성된 파일을 수정할 때는 `scripts/build-extension.py`도 반영해야 재빌드 시 유지됩니다.
확장 파일을 바꾼 뒤에는 확장 관리 화면에서 새로고침하고 분석 탭과 웹페이지도 다시 로드합니다.
